# Uber Data Analytics 🚕📊

## Project Overview

This project analyzes Uber pickup data to identify patterns and trends
in Uber demand across different hours, weekdays, dispatching bases,
airports, and geographical locations.

The project uses Python and data visualization techniques to explore
Uber pickup activity and identify important demand patterns.

## Objectives

- Analyze Uber pickup patterns by month
- Analyze pickup demand across weekdays
- Identify hourly pickup patterns
- Perform Pareto analysis
- Analyze airport pickup demand
- Visualize geographical pickup patterns
- Explore and combine Uber datasets

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Folium
- Jupyter Notebook

## Analysis Performed

### 1. Data Analysis

Explored Uber pickup data and performed data preparation and
time-based analysis.

### 2. Monthly Analysis

Analyzed Uber pickup activity across different months.

### 3. Weekday Analysis

Compared Uber pickup demand across different days of the week.

### 4. Hourly Analysis

Analyzed Uber pickup activity across different hours of the day
to identify periods of higher demand.

### 5. Pareto Analysis

Performed Pareto analysis to identify the major contributors
to Uber trips.

### 6. Airport Analysis

Analyzed pickup demand around major airports including:

- EWR
- JFK
- LGA

### 7. Geographical Analysis

Created geographical visualizations and an animated heatmap
to understand how pickup activity varies by location and time.

## Key Insights

- Uber pickup demand varies significantly throughout the day.
- Pickup demand differs across weekdays.
- Certain hours experience significantly higher pickup activity.
- Pareto analysis helps identify the major contributors to total trips.
- Airport pickup demand varies by location and time.
- Geographical visualization provides additional insight into
  the distribution of Uber pickups.

## Dataset

The project uses Uber pickup data from New York City, including
pickup timestamps, dispatching bases, affiliated bases, and
location information.
